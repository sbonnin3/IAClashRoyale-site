# IA Clash Royale

Publication statique de l’atelier de decks.

Le projet Python, les journaux de combats et les identifiants API restent dans le projet privé et sur le PC.

Les scores sont des estimations. Chaque mode indique la disponibilité et la précision de son modèle.

Les dépendances et sources sont décrites dans THIRD_PARTY.md.
